## 练习 1 · 预测输出 | Guess the output

文件：`practice/02/01_guess_output.cpp`（代码已就位）

先读代码，在每段下面的注释里写**预测输出 + 一句话理由**，再编译运行对照。关注的是「谁在改谁」：

- 引用和指针都指向 x 时，任何一处修改都是改 x

## 练习 3 · 动态数组求平均 | Dynamic array average

文件：`practice/02/03_dynamic_avg.cpp`

1. 输入 `n`，用 `new[]` 分配 `double` 数组
2. 填值：第 i 个元素 = `(i + 1) * 1.5`
3. 求平均输出，保留 2 位小数（`<iomanip>` 的 `std::fixed` + `std::setprecision(2)`）
4. `delete[]` 完整收尾（一个 new 恰好一个 delete）
5. 防御：`n <= 0` 时报错退出——`new` 负数或 0 长度是错的

## 练习 4 · 引用还是指针？| Reference or pointer?

文件：`practice/02/04_ref_or_ptr.cpp`

两个场景，自己实现并测试：

- **场景 A `find`**：在 int 数组里找 target，找到返回**指向那个元素的指针**，找不到返回 `nullptr`
- **场景 B `setMin(int& a, int& b)`**：把较小的值赋给较大的（结果两数相等）

然后在注释里用你的话回答：

1. `find` 为什么**必须**用指针返回？引用行不行，差在哪？
2. `setMin` 用引用比用指针好在哪？
3. 你判断「用引用还是指针」的口诀是什么？
