## ① `30 30 30`

```cpp
int x = 5;
int& r = x;    // r 是 x 的别名
int* p = &x;   // p 指向 x
x = 10;        // x = 10
r = 20;        // 改 r = 改 x → x = 20
*p = 30;       // 解引用改 x → x = 30
```

`x`、`r`、`*p` 是**同一个内存位置的三个名字**，最后一次写入是 30，所以三处打印都是 30。

## ② `1 12`

```cpp
int* p2 = &a;   // p2 指向 a
p2 = &b;        // ⚠️ 改绑：p2 现在指向 b
*p2 += 10;      // 改的是 b：b = 2 + 10 = 12
```

指针**可以改绑**。`p2 = &b` 后 a 就与 p2 无关了。如果这里用引用（`int& r = a; r = b;`）则完全不同——那是把 b 的**值**复制进 a（见示例 01 的输出）。

## ③ `9`

```cpp
*pc = 8;   // 解引用 → c = 8
ref = 9;   // ref 是 c 的别名 → c = 9
```

引用和指针混用时，两条通道都通到 c。谁最后写，就是谁的值。

## ④ `200 100`

```cpp
std::swap(px, py);   // 交换的是两个指针变量：px ↔ py 指向互换
*px = 100;           // px 现在指向 y2 → y2 = 100
*py = 200;           // py 现在指向 x2 → x2 = 200
```

**交换指针 ≠ 交换指针指向的值**。`swap(px, py)` 后：px 指 y2、py 指 x2，所以 `*px = 100` 改的是 y2。如果想交换值，应该 `std::swap(*px, *py)`。

> 这题是 M3 讲「迭代器/排序」的伏笔：很多算法交换的是"位置的指针"，不是值本身。
